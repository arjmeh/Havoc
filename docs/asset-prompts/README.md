# Social asset provenance

This directory records the art direction, source ownership, transformation
steps, and reproducibility constraints for the generated onboarding social
assets.

- [Avatar catalog](./havoc-avatar-catalog.md)
- [Friends animation](./havoc-friends-animation.md)

Both pipelines are local and no-cost. No stock assets were purchased, no paid
trial was started, and no metered image or media service was called while
building these files.
